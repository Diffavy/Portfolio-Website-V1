## Description

This is a personal portfolio site for Harrun Muhiden, available to be viewed [here](https://diffavy.github.io/Portfolio-Website-V1/). Built to showcase software engineering projects and demonstrate front-end development skills.

## Features

An interactive theme selector that gives the choice of three themes: Blueprint (default), Meridian and Nord. A typewriter entrance animation for the header. Modal dialogs for each project with further information for the given project.

## Stack

Vanilla HTML/CSS/JS

## How to run (locally)

1. Clone the repo: `git clone https://github.com/Diffavy/Portfolio-Website-V1.git`
2. Open `index.html` in your browser.

## Learnings & future improvements

Developed an understanding of maintaining visual and stylistic consistency across a site (both in animations and design). Usage of event handlers, DOM manipulation and a variety of entrance animations. Potential improvements: introduce more complex and interactive animations with the ability to be manipulated by the user. For example, using IntersectionObserver scroll animation to display leaf physics.
