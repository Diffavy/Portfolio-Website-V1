The Fighter Comparison - Scraper & Website

I created a web scraper using Python and BeautifulSoup to collect data on MMA fighters from one of the most popular MMA data-rich sites, Sherdog.

The Scraper

Initially, I inspected the site and the specific wrappers for key data points like the name and record of a given fighter. Using their corresponding identifiers and/or class names I created a list of what had to be parsed from the fighter page. Using requests and BeautifulSoup I was able to have a formatted version of the html I originally inspected. Using a variety of helper functions I collated all the necessary data from the fighter's page using a "saveFighter" function which accepts the URL of the fighters page (on Sherdog) as an argument.

The function would create a JSON file for the fighter in a directory called "data", including all of the aforementioned key data points. It also updates the fighter.json file which includes entries for each fighter and the corresponding filepath for their data, which is a necessity for when JavaScript uses the given data.

The Comparison Website

I use the scraper to obtain data on 86 fighters from the UFC, across all of it's weightclasses, and produce a website that shows their key stats head to head. The HTML mainly handles the wrappers and basic formatting of the page, the CSS handles the three column grid layout with each fighter card on either side and the stat labels as the center piece.

The JavaScript uses asynchronous functions to fetch the filepaths for each fighter from "fighters.json". Then using event listeners for both the input and and clicking events (selecting the fighter name from dropdown menu or closing a fighter card) the html is updated. I used a class called "hidden" on a variety of elements, in conjunction with helper functions, to toggle those elements in and out of visibility dependent on user input.

As an example the central stat label divider would only be visible if both fighters have been selected. For some of the stats, like the finish rate and average fight time, I had to do some calculations using data from all of the fights for a given fighter, also implemented in JavaScript. Investigation of electrons tunnelling through potential barriers

In this project, I investigated how electrons interact with different configurations of potential barriers. We start by examining how electrons interact with a single finite potential barrier, then move on to a potential step so on and so forth until we can model arbitrary number of potential barriers. Our main measures of interest are the transmission and reflection coefficients, calculated using the transfer and scattering matrices, as well as the amplitude of the wavefunction across the barriers.
